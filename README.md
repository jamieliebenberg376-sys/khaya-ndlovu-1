# Khaya Ndlovu Game Drive Map

Offline GPS map for game drives at Khaya Ndlovu, with road names, turn-by-turn directions, sightings and road reports.

Open https://jimbojam1213.github.io/khaya-ndlovu/ on your phone, then Add to Home Screen.

- `index.html` the whole app (map engine and road data built in)
- `sw.js` makes it work offline
- `khaya-ndlovu-database.sql` Supabase setup for the shared map
